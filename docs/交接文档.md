## 0. 一句话定位

给 DeepSeek Harness（DSH）加的**个人工作台插件**：侧栏入口（贴在「定时任务」下方）+ 中央聚合面板，面板内 10 张模块卡，**全部由插件本体实现**（无 iframe、无外部链接、数据全在本机）。

当前主力模块是**像素办公室**：一个可交互的 3D 办公室场景，同事 NPC 绑定宿主真实 LLM / agent 会话，支持派活、移交、验收、员工档案（性格/能力/关系链/记忆/3D 模型）。

## 3. 宿主半区（src/）

### 3.1 插件注册 `src/index.ts`

```ts
export const name = 'dsh-personal-workbench';
export const inject: string[] = [];          // 无可选硬依赖，webServer 软探测
export { Config };                            // 导出名必须叫 Config（cordis 按名读）
export async function apply(ctx, config) { ... }
```

`apply` 流程：`resolveDataDir` → `new JsonStore(dir).init()`（失败只 `log.error` 降级，不阻断宿主启动）→ `new KnowledgeClient(...)` → `registerRpc(ctx, {config, store, knowledge, log})`。

### 3.2 `cordis.patch.yml` 铁律

```yaml
- insert:
    - id: dsh-personal-workbench    # ★ 必须等于包名
      name: dsh-personal-workbench
```

id ≠ 包名时：Host 半区照常启动，但 **client bundle 永不广播**（页面白板）。

### 3.3 配置 `src/config.ts`

`personalWorkbenchSchema`：

| 键 | 默认 | 说明 |
|---|---|---|
| `dataDir` | `$DSH_HOME/personal-workbench` | 插件自有 JSON 落盘处 |
| `obsidianUrl` | `http://127.0.0.1:27123` | 知识库（Obsidian Local REST API） |
| `obsidianKeyPath` | `$DSH_HOME/secrets/obsidian-rest-api.key` | API key，**只在 Host 读，绝不下发浏览器** |
| `obsidianTimeoutMs` | `4000` | 知识库请求超时 |

`isLocalHost()` 只允许 `127.0.0.1` / `localhost` / `::1`。

### 3.4 office 端点族（`src/rpc.ts`）

所有端点走 `POST /api/personal-workbench/<endpoint>`，返回 `{ok, value}`；错误 `{ok:false, error:{message}}`。
**GET 分支必须判 `officeMethod === 'GET'` 并置于 POST 之前**（方法控制路由器，否则面板报「⚠️ 仅支持 GET」）。

| 端点 | 作用 |
|---|---|
| `office/chat` | SSE 聊天（群聊/私聊共用） |
| `office/npc/chat` | NPC 私聊 SSE（含角色语气注入） |
| `office/agent/start` / `say` / `stop` / `handoff` | 派活真 agent 会话（start/say/停止/移交） |
| `office/agents` | GET：列出在跑的 agent 会话 |
| `office/roster` | GET 花名册；POST 入职 |
| `office/roster/builtin` | POST：更新内置员工档案（PATCH 语义） |
| `office/roster/autopilot` | 自觉工作开关 |
| `office/memory` | 员工记忆增删清（POST `{char, remove:index}` / `{char, clear:true}`） |
| `office/state` | 场景状态（角色位置/状态/会议） |
| `office/actions` | GET：take-and-clear 动作队列（客户端轮询 1.5s） |
| `office/action` | 单条动作 |
| `office/models` | GET：`listProviders()` × `listModels()` 枚举可选 LLM（每源单独 catch→[]） |
| `office/asset/list` / `office/asset/get` | 资产枚举/读取（白名单 `/^[\w.-]+\.(obj|mtl|glb|gltf)$/`；glb/gltf 走 base64） |
| `office/workdir` / `office/workdir/pick` | 工作区读写 / 原生 macOS 目录选择器（osascript） |

### 3.5 员工档案 `src/office-roster.ts`

```ts
type OfficeBuiltinOverride = {
  name?; role?; persona?; links?: string[]; autopilot?: boolean; deskId?;
  provider?; model?;                      // LLM 覆盖：空串/缺省 = 跟随宿主全局默认
  skills?: Record<string, number>;        // 固定维度 OFFICE_SKILL_DIMS = 代码/架构/测试/设计/沟通/业务/数据
  avatar?: string;                        // 3D 模型文件名（/^[\w-]{1,56}\.(gltf|glb)$/）
};
```

- `upsertBuiltinOverride(id, patch)`：**字段缺失 = 不变，空串 = 清除**。
- `builtinOverrideOf(id)`、`personaPromptSuffix`（把性格/能力/关系链注入 agent 提示词）。
- 落盘：`<dataDir>/office_agents.json`（结构 `{roster:[...]}`）；记忆 `<dataDir>/office_memory/<charId>.json`（≤50 条）。
- 内置 NPC id：`npc-1` ~ `npc-6`。

### 3.6 dsh-llm 契约（踩过的坑）

- `messages` 的 `content` **必须是块数组** `[{type:'text',text}]`，否则报 `content.some is not a function`。
- 流式增量字段是 `text`；`finish.reason` 为 `{kind:'error'|'aborted', failure:{...}}`。
- 传 `stop` → `UNSUPPORTED_OPTION`。
- `officeSse(systemContent, msgs, modelOverride?)`：第三参为员工模型覆盖；**覆盖生效时跳过 `reasoningEffort`**（给非思考型快模型传思考参数会报错/静默流式超时）。
- 派活 agent：`agents.create` **必传 `sessionId`**（不变式 `agent.id === session.id`）+ `meta:{cwd}`（缺失会报 `prompt variable "{{cwd}}" has no value`）+ `presets.mount`；助手流以 `{frame}` 包装，帧 `{type:'start'|'chunk'|'end', chunk, outcome:{kind:'committed'|'abandoned'}}`。
- 「stream idle timeout after 300000ms」= 宿主看门狗对**上游 300s 全静默**的掐断，不是总时长限制。

## 5. 像素办公室架构

### 5.1 地图与引擎（`client/src/office/map.ts` / `engine.ts`）

- 地图 **`MAP_W = 40` × `MAP_H = 12`**；墙环 = 外圈一圈。
- 合法性：`inWalls(x,y,w,h)` = `x>=1 && y>=1 && x+w<=MAP_W-1(=39) && y+h<=MAP_H-1(=11)`。
- `FURN_SIZE`：desk 2×2 / whiteboard 2×1 / plant 1×1 / coffee 1×1 / wall 1×1 / microwave 1×1 / fridge 1×1 / carpet 4×3 / roundtable 2×2 / cabinet 1×1。
- `buildBlocked()` 里地毯通过 `continue` 跳过 → **地毯可通行**（是地面铺层）。
- `defaultMap()`：39 件家具、8 张工位；**`desks` 数组最后一个 = 自己（Yuze）的工位**，`addAutoDesk`/`addRosterChar` 都在头部插入以保住这个不变式（`desk-roster-<id>`）。
- 寻路：BFS（`path()`），支持负坐标（arena 延伸走位区）。
  - ★ **起终点都在房间内时 `bounded = true`，BFS 只允许「房间内且 `blocked===0`」的格子** —— 否则外圈墙在 `arena>0` 时被 `free()` 当「门口」放行，NPC 为抄近路会绕到屋外沙地。
  - `tickChar` 兜底：非走路状态却在房间外 → 直接归位到自己工位椅位并转 `working`。
- 椅子格：`deskChairCell(desk) = {x: desk.x, y: desk.y + desk.h - 1}`；3D 里的落点 = 该格中心 `(f.x+0.5, f.y+1.5)`。
- 意图 `decide()`（当前概率）：回工位 **0.75** / 咖啡 0.10 / 串门 0.08 / 兜底闲逛；工作时长 `rand(24, 50)` 秒；初始在工位 `rand(30, 60)` 秒。
- 气泡默认挂头像左侧，`bx < 4` 时翻到右侧，不遮姓名。

### 5.2 渲染：2D（`renderer.ts`）与 3D（`scene3d.ts`）

- `renderOffice(canvas, furniture, chars, time, opts)`：`opts.topDown === true` 走 2D 俯视（编辑器用），否则等距 2D。
- 等距 2D 数学：`k = min(cssW/(MAP_W+MAP_H), cssH*2/(MAP_W+MAP_H)) * zoom`；`wx=(gx-gy)k`，`wy=(gx+gy)k/2`；逆变换 `gx=(a+b)/2, gy=(a-b)/2`；静态层缓存键前缀 `iso3:`。
- **3D 场景（主用）** `renderScene3d(canvas, bubbleCanvas, furniture, chars, time, opts) → boolean`：
  - three `0.186.0`，正交相机；方位角 / 仰角标准等距；`camera.position = T + D·(0.866·R2, 0.5, 0.866·R2)`，`D = 120`；整体绕地图中心 `pivot.rotation.y = -rot·π/2`（或连续角 `rotDeg`）。
  - `opts: { zoom, panX, panY, rot, rotDeg?, meeting?, bubbles, dt? }`。
  - **返回 `false` = 场景不可用**（`ensureScene` 返回 null / `glCtx.isContextLost?.() === true` / 相机参数 `P = √2·k` 退化为非有限或 ≤0）→ 调用方 `setOverlayFailed(true)` 永久回退 2D，避免留永久空白画布。
  - 光照（泛白治理后）：`AmbientLight(0xfff1e0, 0.42)`、`environmentIntensity = 0.22`、`HemisphereLight(0xffffff, 0xb9a888, 0.3)`、主光 `(0xffeecb, 1.42)`、补光 `(0xe8eeff, 0.22)`。
  - 调色板：`C_BG '#e9ebee'`、`C_BASE '#eceef0'`、`C_FLOOR '#d4b177'`、`C_WALL '#f0f2f4'`、`C_METAL/C_GLASS` 等。
  - 室内木地板只铺 `MAP_W+0.04 × MAP_H+0.04`；室外 200×200 台面用**径向 CanvasTexture**（中心 `#ece9df` → 0.55 `#e4e0d5` → 边 `#d3cec1`）。
  - 玻璃隔断 `buildGlassCell`：**竖梃只在整段两端加**（`!wallSet.has(相邻格)`），否则每格两根柱 → 13 格连成黑栅栏。
  - 拾取 `pickCell3d(canvas, cssX, cssY, opts) → Vec|null`：Raycaster 打不可见 `pickFloor(160×160, userData.isPickFloor=true, y=0.08)`。
  - 人物实例存 `instances: Map<id, {...}>`；**必须 `SkeletonUtils.clone`**（普通 `clone(true)` 丢骨骼绑定 → 人物不可见）。
  - 坐姿：椅位/落点用引擎椅位 `(f.x+0.5, f.y+1.5)`；朝向对准显示器 `monZ = desk.y + 1 - 0.61*0.5 + 0.16`；`seatLift = 0.1`。
  - 动画三态权重互斥：`want = walking ? 'walk' : seated ? 'sit' : 'idle'`；`seated = working || (非 walking && 距自己椅位 < 0.6)`。
  - 名字/气泡在独立 2D canvas 上按渲染锚点投影绘制。

### 5.3 人物与家具资产（`client/src/office/objModels.ts` + `assets/models/`）

- 52 个 `.gltf` 骨骼人物（各含 `skins:1`、17 个动画剪辑：Idle/Walk/Run/SitDown/Death/Jump…），随包自包含 base64 buffer。
- 家具 GLB：`desk → Table.glb`（棕色木桌，视觉高 0.78）、`chair → Chair.glb`（红/橙办公椅，0.62）、`Plant/Microwave/Fridge.glb`；`roundtable` 用几何白圆桌。
- `FIXED` 表按名字固定映射（Yuze → Suit_Male.gltf 等），否则名字 hash → 14 项池；`setAvatarOverrides()` 注入员工档案里手工指定的模型（`modelForChar()` 优先返回它）。
- **材质染色按名字匹配**（glTF 的 `baseColorFactor` 是线性暗值，按色值匹配必失败）：
  - 员工色：`/shirt|body|torso|cloth/i` → `c.color`
  - 肤色提亮：`/skin|face|head/i` → `0xf2c79f` / 脸 `0xf6d7b8`
- 金属面（冰箱）无环境反射会渲染成黑块 → 需 `PMREMGenerator` + `RoomEnvironment`。

### 5.4 交互（`OfficeCanvas.tsx` + `OfficeModuleView.tsx`）

- rAF 循环宿主：`overlayRef.current ?? canvasRef.current`（3D 用 WebGL 画布，2D 回退用普通 canvas）——**首帧若判空直接 return 会杀掉循环（白屏）**，历史踩过。
- 左键拖平移；滚轮缩放 `factor 1.12`、`clamp 0.5–2.5`、原生监听挂容器 div；右键拖连续旋转（0.5°/px）。
- `handleClick`：3D 走 `pickCell3d`，2D 走 `cellAtPoint`；点同事打招呼+私聊，点空地走位，点白板前缘开会。
- 三 tab：**场景 / 员工档案 / 布置办公室**；右侧「我的员工」+ AI 助手，左右分栏比例存 `dsh-pwb:office_split_v1`。
- 聊天持久化键：`dsh-pwb:office_chat_v1:ai` / `:group` / `:npc:<id>`（100 条）。
- 动作轮询 1.5s 调 `office/actions`（take-and-clear），404 → `actionsDeadRef` 停止轮询。

### 5.5 布置办公室编辑器（`OfficeEditor.tsx`）

- **地图唯一真相源：以 `engine.map` 为初始值**（`<OfficeEditor map={engine.map} …>`），不再各自读 localStorage —— 这是「编辑器与场景显示不同地图」的结构性修复。
- 2D 俯视渲染复用 `renderOffice(..., { topDown: true })`；家具目录 10 项，点选进入放置模式，Esc 退出；撤销/重做 ≤50 步。
- 保存：`saveOfficeMap()` 写 localStorage + `onSave` → `setEngine(new OfficeEngine(m))`。
- 场景右下角「⟲布局」= `clearOfficeMap()` + 重建 `defaultMap()` 引擎。

## 7. 已知坑与教训（按踩坑顺序）

1. **dsh-llm `content` 必须是块数组**，否则 `content.some is not a function`。
2. **`agents.create` 必须带 `sessionId` + `meta:{cwd}`**：缺 sessionId 报 `agent id "undefined" does not match session id`；缺 cwd 报 `prompt variable "{{cwd}}" has no value (section "deployment:persona-suffix")`。
3. **rAF 循环首行判空 `canvas` 会杀循环** → 白屏 / 滚轮失效。
4. **Three.js 共享模型 `add` 到新 parent 会从旧 parent 移除** → 家具只剩最后一个；多处摆放必须 `SkeletonUtils.clone`（骨骼蒙皮尤其）。
5. **glTF 材质是线性暗值** → 染色按**材质名**匹配，不按色值。
6. **PBR 金属无环境贴图 = 黑块** → `PMREMGenerator` + `RoomEnvironment` + `environmentIntensity`。
7. **相机 / 拾取数学必须与渲染一致**（Raycaster 打不可见拾取面），否则「命中与人物脱离」。
8. **`corner-shape: superellipse(1.5)`** 全局生效，圆角需 `corner-shape: round`。
9. **地图存档校验曾是白名单**，漏 kind 会导致整包拒绝 → 现改为 `Object.keys(FURN_SIZE)`；defaultMap 自身不得含越界家具（`plant@39,10`、`fridge@39,1` 曾致存档必失败）。
10. **地毯必须豁免重叠校验**（它是可通行地面铺层，参考图里圆桌就压在地毯上）。
11. **泛白**：环境光 1.25 + envIntensity 0.55 + 近白地面叠加过曝是主因；现已下调（§5.2）。
12. **`dist/**` 已在 .gitignore**，别手改产物；断言产物要容忍 esbuild 改名（`r→r2`、`-1000→-1e3`、去类型注解、双引号）。
13. **typecheck 用管道会吞退出码**，必须显式 `echo "TC=$?"`。
14. **GitHub push 偶发 SSL 失败** → 用重试循环（本仓库习惯 `for i in 1 2 3 4; do sleep $((i*8)); git push && break; done`）。
15. **压缩/上下文**：本会话 bili 压缩工具因 native-compaction 重写 refs 而失效；遇到时不要反复重试。

## 10. 常用排障

| 症状 | 先查 |
|---|---|
| 改了没生效 | 是否只强刷（client）/ 是否 ⌘Q 重启（src）；副标题的「构建」时间是否等于最新构建 |
| 「未知端点」 | 宿主跑旧代码 → 重启宿主 |
| client bundle 不广播 / 页面空白 | `cordis.patch.yml` 的 `insert.id` 是否等于包名 |
| 场景整片空白 | WebGL 上下文丢失 → 应已自动回退 2D；查 console 与 `renderScene3d` 返回值 |
| 人物不可见 | 是否用了 `SkeletonUtils.clone`；骨骼绑定是否丢失 |
| 人物黑剪影 | 材质名匹配（§5.3） |
| 存档读不回（地图变默认） | `store.ts` 校验：kind 白名单、越界家具、地毯重叠 |
| 面板提示「仅支持 GET」 | 路由 GET/POST 分支顺序 |
| 装修页提示文字压住入职行 | `.dsh-pwb-office-ed-catalog` 的 `max-height: min(58vh, 520px)` |
